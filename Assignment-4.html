GitHub Repository with Three Meaningful Commits

Objective

To create a GitHub repository and make at least three meaningful commits to track changes in a project.

Step 1: Create a Project Folder

mkdir my-project
cd my-project

Step 2: Create an HTML File

Create a file named index.html and add the following code:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>My First Project</title>
</head>
<body>
    <h1>Welcome to My Project</h1>
    <p>This is my first HTML project.</p>
</body>
</html>

Step 3: Initialize Git

git init
git add index.html
git commit -m "Add initial HTML page"

Step 4: Make Three Meaningful Commits

Commit 1: Add Initial HTML Page

git add index.html
git commit -m "Add initial HTML page"

Commit 2: Add Project Description

Add this paragraph inside the body of index.html:

<p>This project demonstrates basic HTML structure.</p>
git add index.html
git commit -m "Add project description"

Commit 3: Add More HTML Content

Add this heading and list inside the body of index.html:

<h2>My Learning Goals</h2>
<ul>
    <li>Learn HTML</li>
    <li>Learn CSS</li>
    <li>Learn JavaScript</li>
</ul>
git add index.html
git commit -m "Add learning goals section"

Step 5: Verify Commits

git log --oneline

Step 6: Push to GitHub

Create a new repository on GitHub, then run:

git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main

Expected Result

  • A GitHub repository containing index.html.
  • At least three meaningful commits.
  • A project history showing the changes made.

Conclusion

I created an HTML project, tracked changes using Git, made three meaningful commits, and pushed the repository to GitHub.
