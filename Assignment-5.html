```html GitHub Push Steps

Push Steps

  1. On GitHub.com, click New repository. Name it html-css-assignments. Leave it empty (no README), then click Create repository.
  2. In your local project folder, run these commands: 
    git remote add origin https://github.com/<your-username>/html-css-assignments.git
git branch -M main
git push -u origin main
  3. Refresh the GitHub page and confirm all files and commits appear.

Optional: Host It for Free

Go to Settings → Pages. Select main as the branch and / (root) as the folder, then click Save.

Your website will be available at:

https://<your-username>.github.io/html-css-assignments/
```
