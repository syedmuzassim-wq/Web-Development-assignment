What happens between typing a URL and seeing the page?
When you type a URL into a browser and press Enter, the following steps happen:


1. URL Parsing: The browser understands the website address and protocol, such as HTTPS.

2. DNS Lookup: DNS converts the domain name into an IP address.

3. Connection Establishment: The browser connects to the server using TCP and TLS for secure HTTPS connections.

4. HTTP Request: The browser sends a request to the server for the webpage.

5. Server Response: The server sends back HTML, CSS, JavaScript, images, and other resources.

6. Rendering: The browser processes these resources, builds the page layout, applies styles, and executes JavaScript.

7. Page Display: Finally, the browser displays the webpage on your screen.

In short: URL → DNS → Connection → Request → Response → Rendering → Webpage.
