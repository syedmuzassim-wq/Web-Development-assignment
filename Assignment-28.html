Overflow – Fixed

Learn how to fix common CSS overflow problems.

1. Responsive Image

Fix: max-width: 100% prevents images from exceeding their container.

2. Long Unbroken Text

https://www.example.com/this/is/a/very/long/url/that/would/normally/stretch/the/layout/sideways/forever/and/ever

Fix: overflow-wrap: anywhere allows long URLs and words to wrap.

3. Wide Table

ID Name Email City Course Year
1 Pawan pawan@gmail.com Bareilly BCA-AI 2028
Fix: overflow-x: auto makes the table scroll horizontally when needed.

4. Fixed-Height Box

Lorem ipsum dolor sit amet, consectetur adipiscing elit. Sed do eiusmod tempor incididunt ut labore et dolore magna aliqua. Ut enim ad minim veniam, quis nostrud exercitation ullamco laboris nisi ut aliquip ex ea commodo consequat. Duis aute irure dolor in reprehenderit in voluptate velit esse cillum dolore eu fugiat nulla pariatur.
Fix: overflow-y: auto adds vertical scrolling when content is too long.

5. Code Block

const message = "This line is intentionally very long so that it would overflow the container if not for overflow-x: auto";
Fix: overflow-x: auto allows long code to scroll horizontally.
