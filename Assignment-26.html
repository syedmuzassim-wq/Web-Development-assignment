CSS Box Model of .my-box

```
Hello
MARGIN 30px
BORDER 10px
PADDING 20px
CONTENT
200 × 80
```

📐 Box Model Calculation

```
Property Calculation Total
Content Width 200px 200px
Total Width 200 + (20 × 2) + (10 × 2) 260px
Width with Margin 260 + (30 × 2) 320px
Total Height 80 + (20 × 2) + (10 × 2) 140px
Height with Margin 140 + (30 × 2) 200px
```

📦 With box-sizing: border-box

```

The same width: 200px would already include padding and border, so the box would stay 200px wide.

The content width shrinks to 140px because: 200 - 40px padding - 20px border = 140px.

That's why most developers add: * { box-sizing: border-box; }

```
